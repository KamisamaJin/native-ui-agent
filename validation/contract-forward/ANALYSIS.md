# Failure model and boundaries of the change

V5 established native facts and a complete declared state matrix. The same agent
could still interpret a requirement incorrectly twice: once in production code,
then again in its expected values. A source field naming a whole brief did not
check an individual value, unit, state or design revision. More native frames did
not resolve that shared assumption.

V6 introduces a separate approved typed design artifact, exact source-file hashes
and JSON Pointer anchors, unit-safe derivations, immutable per-state disposition,
and deterministic assertion generation. Runtime execution reconstructs a generated
plan against the externally pinned lock digest. Target bindings are separate from
expected values; action routes are fixed independently too. Incorrect generated
values, tolerance changes and omitted state cells are rejected before asserting
product quality. Legacy plans are labeled unverified rather than silently claiming
that protection.

This does not automate semantic truth. A separately approved design could itself
be wrong; an exact JSON Pointer could point to a semantically inappropriate token;
a selector could bind the wrong native node. Hashes prove identity and derivation,
not authorship, design correctness or target correctness. Independent design review,
preimplementation sealing and a separate acceptance oracle remain necessary.

Styles are observed according to actual capabilities. Android native TextLayout
exposes several text styles. Public iOS AX does not provide generic computed
SwiftUI font/color. Native box distances can establish visible geometry when both
boxes are unique and fully visible in the same frame; these distances do not prove
a framework padding attribute or physical hit region. Unsupported cells stay U.

Collector cost work changes navigation planning, not observation obligations:
nearby unseen native boxes first, one original coherent viewport reused for all
targets, fixed global scroll budgets and original immediate callback intervals.
Native geometry only guides navigation; a subsequent captured native frame must
establish the asserted fact. Failed searches and acquisition failures remain in
the denominator and evidence. An optimization that increases time or loses facts
is reported as such.
