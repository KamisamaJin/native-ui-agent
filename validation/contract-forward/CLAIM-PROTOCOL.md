# Original-claim normalization and matching

Fixed before original reviews complete and before independent source grades.
Original root-executed typed-native reports are immutable. Include every failed
non-manual assertion as a machine claim in both arms, whether a model repeats it
or not. Read expected/state/requirement from that arm's original plan, never from
the independent oracle. Match public requirement_id (or its exact state/rule ID),
case, platform and state; retain any missing/unmapped descriptor. The independent
frozen matcher checks expected semantics, including ARGB representation, and does
not credit a wrong expected value as a correct detection.

Manual failed findings must identify an actual original state/aspect and cite
actual original screenshot/report artifacts with valid SHA256. Preserve original
claim text and uncertain/missing evidence. Proof-ineligible claims stay uncertain,
not TP/FP. Duplicate flags remain in the ledger without multiplying detected
failures. Report machine-only, manual-only and combined matching separately.
No later source cause/repair backfills original detection of another state.

Use the frozen design-owned match_claims/repair functions for eligible original
claims. Required assessed natural F rows without an original exact detection are
missed; P/F/U and N/A stay separate. Conditional FDR is FP/(TP+FP), with unknown
claims reported and conservative bounds shown. Classical FPR is N/A without a
complete negative claim universe. Natural business_current observations and gated
business_transition callbacks get separate panels. Zero denominators are N/A.

Same-source collector comparisons use the same input/action files and frozen
native grading policy, with manual=None on both sides. Compare native_content,
business_current, business_transition, style_native and native_geometry only;
visual/API/input judgments do not become collector gains. The already acquired
common-v6 D0 raw and native-base grades may be reused byte-exact. The v5 side is a
separate actual acquisition. Keep all gained/lost/assessed-conflict rows and all
native command time including failures; original/paired capture order and shared
Mac contention limit speed attribution.
