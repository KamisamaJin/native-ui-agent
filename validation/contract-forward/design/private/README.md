# Frozen independent acceptance

This designer was assigned only the design task, frozen contract tooling and neutral schema example. No assignment, prior trial content/results, candidate implementation, builder plan, source or candidate image was inspected during design. A broad initial filename listing exposed names of other trial directories, but no contents were read. The designer subsequently read frozen design_contract.py, reference documentation, neutral schema example, native_checks.py, observation_contract.py and observer transport declarations solely to obtain supported schema and callback/state provenance. Shared filesystem blindness is procedural: there is no OS access barrier or proof that another agent could not read private files. Builders must receive only public/; root must retain the independently reported canonical lock digest and this seal outside builder edit scope.

The chosen ordinary business component is a workshop enrollment card. Public P1 has 5 states, P2 6; hidden H1 has 5 states, including removal and complete unavailability. The fixed acceptance table has 24 families × 16 states × 2 platforms = 768 runtime cells. Every rule/state/platform cell stays in the denominator; N/A means explicitly inapplicable, U means applicable but unsupported/unobserved. Source/API/input checks are separate. No outcome denominator may silently drop U or N/A. Natural defects are runtime F cells; partition business_current/business_transition, style_native, native_geometry, native_content and visual. A zero natural-defect denominator is N/A.

The oracle reducer and fixed typed references were written before source. `acceptance-table.json` freezes every expected value and disposition. `grader.py` loads only our sealed plans/lock, checks every expected against this table and uses frozen native facts/state resolution/callback gating. It never trusts a builder-supplied plan or expected value. Runtime current-state values are distinct from transition evidence. Callback rows require demonstrated successful requested dispatch; disabled/no-dispatch empty intervals remain U, not quiet business passes. Android OnClick is semantic activation, not physical touch. iOS computed typography/color/ellipsis remains U even if some untrusted observation fields claim values. Box geometry means fully visible native semantic/control frames; no text-width-to-layout inference. 44pt/48dp is a lower bound, with no float equality. Font serialization tolerance is fixed at 0.05sp. Ellipsis false is explicit where actually measurable; no generic clipping or effective padding inference is licensed.

`reserve-visible` is the sole selected visual judgment: actual Reserve-label glyphs fully visible without clipping/ellipsis at each selected state. Manual decisions must cite actual screenshot indices, files and hashes for that observation; otherwise U. This does not assess full visual similarity or exact iOS computed styles. Unscored prose tokens are listed explicitly in public/BRIEF.md. Screenshots referenced by observations are relative to each capture, never the project root.

Use: `python3 design/private/grader.py --root <contract-forward or repo root> --case P1 --platform ios --observation <capture/observation.json> --output <fresh grade.json>`. Optional `--manual` uses frozen native manual decision schema; `--source-root` checks production file placement; `--api-review` accepts separately evidenced manual source/API decisions with exact frozen expected, P/F, reason and artifact SHA256. Public signature verdict requires actual source inspection and pinned-host successful compilation; no source means U. Run-manifest input hashes are checked against our exact fixture and compiled action bytes. The adapter remaps former absolute /validation/contract-forward/ paths when replayed from a clean archive. Every emitted runtime row includes id, case, platform, state, requirement/aspect, class, P/F/U/N/A, expected, actual, evidence refs, snapshot indices and reason.

`test_grader.py` is SDK-free and uses neutral synthetic observations: correct/wrong labels, unknown states, callback success/failure/no-dispatch, caller epoch gate, layout unsupported, numerical serialization, equal machine/manual matching and fixed-row repairs. These are grader controls, not candidate observations. The grader and controls have a separate pre-source GRADER-SEAL.json. Preserve all grade attempts; never overwrite outputs.

Self-review: `match_claims` applies the same exact case/platform/state/aspect plus expected value/unit matching to typed failed rows and manual findings. A wrong expected value is not correct detection. Adjudicated F claims are TP; adjudicated P claims are FP; uncertain, N/A, unmapped or wrong-expectation claims remain explicit. Report conditional FDR over adjudicated claims and uncertainty counts; classical FPR is undefined because no complete negative claim universe exists. Recall is per fixed natural-F rows, including separate class metrics. `repair` follows the same frozen D0 F rows to FINAL P/F/U; missing rows or changed expectations become U. No defect injection or post-result expectation edits are allowed.
