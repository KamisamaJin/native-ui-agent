# Common operations fixed before new design/implementation

Both arms receive the same independently fixed public typed reference, human
brief, scenarios, API, bridge, literal input fixtures and original action routes.
The public design owner writes the contract, rather than the implementation agent.
V5 uses its frozen Skill to translate self-check plans; v6 uses its frozen compiler
and externally pinned lock. Neither may change approved values, conditions or
routes to fit a result. Missing observability stays explicit. Neither receives
private heldout values or evaluator rules during development.

Both initial sources seal before any render feedback. Native collection has one
iOS and one Android slot per arm on separate owned simulator/Gradle workspaces.
Arms may overlap on this one Mac. Both own D0 corpora seal before either original
read-only review. Own original plans and typed reports seal before repair; review
cannot edit production. One bounded repair may compile, but no new rendered image
is seen until both FINAL sources seal. Own FINAL public native capture follows to
close each primary implementation-to-evidence wall endpoint. Only then prepare
common FINAL heldout stimuli. Record actual barriers and contention in costs.

Common acceptance uses the frozen v6 observer for both D0 public and FINAL
public+heldout sources. The independent grader compares anonymous sources with
its design-frozen acceptance policy. Both D0 grades seal before FINAL grading is
delivered, and both FINAL grades seal before original-self-review matching. The
assignment reveal follows all three dual seals. Same-source public D0 v5 captures
are separately acquired; their v6 side reuses the common D0 bytes exactly. Pair
fact/status comparisons are deterministic under the same frozen common grading
policy, separate from self-review detection matching.

Native callbacks use the unchanged established-dispatch gate. Geometry states
whether it means public native accessibility/semantic boxes or layout allocation;
the latter is unsupported by these collectors, even if two numbers happen to
match. iOS computed text styles and OS physical hit regions remain unsupported.
Private controls test scoring primitives before source grading. Any common host,
scoring or archive repair is documented for both arms, without credit to v6.

The two clean pinned upstream workspaces were bootstrapped before design. Setup
argv/log/timing, random unit/tool assignment and all subsequent source/input/
corpus hashes are retained. Procedural blindness uses separate minimal-context
agents and sealed batches; shared filesystem and recognizable formats remain
limitations. Model versions/settings inherit the same session default. There is
no manual font-specific correction or task-specific change to frozen tools.
