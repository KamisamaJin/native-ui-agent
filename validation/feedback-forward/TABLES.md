“完整自身验收端点”包括最终完整原生采集、看图、源码审查和实际 Swift 模块/调用方最低 API 校验，失败端点仍计成本。accepted=false 时不能声称成功交付耗时；成功交付成本不可得。原始自动端点保留以对应预注册主口径。

可归属路径将相同的初始编写和初始采集全额计入两组，再加接手到自身完整端点。实际墙钟还包含等待另一任务封存、操作员排程等实验成本。原生资源时间可以重叠，不与墙钟相加。外部双评、开发本 Skill、设计修订和 CI 成本另列。tokens/金额未精确记录，保持未知。
