V7 is a separately versioned positive-provenance composition. The frozen controller accepts untyped worker selfclaims with a nonempty statement; that alone does not establish metadata responsibility. V6 conservatively rejects physical paths under any protected-prefix ancestor. V7 can normalize a narrow provenance object or scalar under a compound summary name only when it positively matches already selected, pinned original artifacts. Authority is established by Group's original operations and event-pinned public results. Preparation registers each selected original operation ref, and registers public result refs with the exact original request_finished event ref from the verified native read set. These authority rows stay in the operator-only SPEC.provenance_authorities, outside anonymous_description and judge files. During packaging selected_provenance_authorities binds operation authorities to this spec's operation-result derivations, raw hashes and selected documents. Public result authorities require matching pinned event/result scope and exact JSON outcomes already selected in the group. Boolean/number substitutions and duplicate outcomes reject. Cause/group/spec/code/selection authority must already be established by the caller; this helper does not authenticate an arbitrary freshly repinned spec.

The reference registry is recomputed from pinned raw operation/result bytes. It verifies each target's original byte SHA. It recognizes capture/cycle/completion/bound_review refs, event-bound public result self refs, and original pinned service inventory members. A resource receipt must be the original resources.json inventory artifact. Inventory paths must remain within the original service namespace, and row SHA/byte forms are checked. Object roles are an explicit source/protocol policy: capture/capture_receipt, cycle, completion, bound_review, result/request_result/original_result and resources/resource_receipt. There is no arbitrary role inference. Scalar metadata leaves must end in _path, be nonprotected, and exactly match a registered target. No path prefix is guessed.

The only new substitutions are the physical path of an exact path/SHA object, or one registered scalar metadata path. Opaque record-ref values use the exact registered original path/SHA pair's full digest. All object SHA values, claim assertions, statuses, numbers, text and array positions remain. Exact raw actual/expected/observed/rendered/measured/payload/text/value/status and other protected fact ancestors remain blocked, including common actual/expected/etc value aliases. A protected leaf such as actual_filepath is blocked even when its value names a registered target. Unknown roles, extra-field objects, forged hashes, arbitrary business path/hash objects, foreign or unavailable refs and unsupported scalar roles reject. Ordinary unprotected metadata keeps its previous behavior.

Each operator admission records the exact pointer, original/anonymous path, registered target, source role and pinned parent authority. It labels the substitution as opaque original provenance, with no supplied-file or factual-truth assertion. Only the authorities actually used enter that row's proof. Replay requires those authorities to be members of the caller's independently bound selected-spec authority set; a row cannot nominate a foreign parent. It re-reads pinned parents/targets, recomputes the admission from raw bytes, and then replays the unchanged bounded projection and derived byte pin. Nonempty provenance proofs fail when the optional caller context is absent. This API handoff is explicit in REPLAY-HANDOFF.md; consumers require separate review before actual use.
