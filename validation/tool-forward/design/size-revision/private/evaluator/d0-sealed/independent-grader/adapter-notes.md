# Independent raw normalization notes

These are implementation details of this evaluator's new adapter, not changes to the frozen oracle, public requirements, evidence classes, initial inputs, holdouts, or acceptance policy. The selected design and pre-evidence evaluator preparation remain byte-for-byte intact. No production source was changed, no tool/Skill implementation was read, and no report/self-review/assignment or old-collector evidence was read.

- Actual fixture JSON wraps models under `model`. Semantic equality compares the complete unwrapped object to the frozen context; native serialization hashes need not agree between platforms. Actual manifest business-file hashes bind each runtime to the anonymous production seal.
- Each checkpoint binding retains the actual native configuration/category/theme/direction/offered viewport observations and their precise raw locations in addition to the frozen expected environment hash. These environment observations are not resolved-font or invisible-hit-region measurements.
- Callback intervals include every executed native step after the preceding checkpoint through the current capture. The initial native event buffer is also inspected. Actual zero/count/payload facts remain separate from delivered-activation proof. A requested activation that was unavailable cannot establish a bad business handler, even when the frozen interval expectation is unmet.
- The actual method is recorded as Android native semantic OnClick, iOS XCUI tap, observer-declined disabled dispatch, or unavailable dispatch. Requested labels never stand in for execution. Method limitations do not erase actual callback observations.
- An actual named native control can be correlated by unique complete caller content, native role, geometry, and input epoch when its identifier is wrong. That observation does not repair or pass the separate stable-identifier-set predicate. An inherited root identifier on text/control descendants is not a component root frame. Missing root geometry is explicitly unknown rather than measuring a random descendant as the card.
- A raw `complete` summary may additionally require constant lazy-layout height. The frozen reach/coverage predicates concern actual top/bottom reach, stable input, overlapping viewports, and observed content. The original captures, actual card bottom, intervals, and field coverage take precedence over a summary flag alone. A changing lazy height is not an automatic UI defect.
- Native screenshot colors are sampled from actual flat fills or glyph/border cores. Circular raster corners are fitted to foreground edge samples with subpixel placement allowed; no source radius is used. Representative spacing uses actual raster edges and calibrated native viewport/scroll coordinates. Line-box spacing remains unknown when only glyph ink is available.
- A complete field area can be captured and visibly clip letters. That is observed capture coverage and an actual readability/overflow mismatch; it is not an unseen field or an invented complete string. Derived images are lossless parent-viewport crops/pastes for navigation. Original paths, hashes, crop coordinates, and native offsets remain primary evidence.
- Actual native `touch_bounds_dp` supports Android hit-region minimums, including a sufficient viewport-clipped lower bound. A clipped region below a minimum does not prove its full hit rectangle fails. Apple AX frames/hittable flags and isolated tap points do not establish physical hit dimensions.
- Minimum hit dimensions use the frozen literal thresholds, with no extra half-unit allowance. A draft adapter allowance was removed during integrity review; every assessed native dimension already met its own threshold, so this correction changes no entered outcome.
- A native text-layout `font_sp` value can establish the base-size range only. It cannot establish a resolved family/face or effective physical scaling. Active environment settings establish the environment sample, not runtime typography by themselves. Source font declarations never become runtime typography evidence.
- Ordinary static-text roles do not establish heading traits. Querying structural image descendants does not establish independent accessibility focusability. Unsupported sub-aspects remain explicit per-key unknowns, with available raw evidence retained separately from missing methods.
- A case is consumed only after both its capture and portable hash inventory are published. The final evidence inventory preserves every screenshot referenced by every native snapshot, including before/after captures outside the selected assessment views, verifies raw JSON/PNG bytes against the portable commitments, and retains the original capture status and native exit code. Operational status labels and native nonzero exits alone do not decide component quality.

Working drafts and partial ledgers are not outcome seals. Pending iOS cases are excluded from the partial decision ledger and listed as `pendingNotGraded`; they are not finalized as unknowns. Both complete D0 grades, exact source/input/evidence inventories, per-state/aspect/group rollups, actual activation methods, and defect clusters are frozen together before review matching. The outward seal contains no quality results.
