## 盲测如何执行

工具/方法/中性资格先封存 [RELEASE.json](RELEASE.json)。独立设计者固定公开与隐藏输入、样式、状态、动作、责任和评分；[独立设计批准](business-design-review/approval.json)后，唯一作者只读取公开设计，编译自然初版，不运行 UI 自测。初版仅新增两个生产文件，原项目文件未改；源码原字节复制到 A/B 后才首采。

组件包含替代菜选择、数量与余额、不可用选项、调用方更新、错误/撤销恢复及确认回调。公开为 light/LTR/390 单位；隐藏为 dark/RTL/320 单位/大字体和长阿拉伯文，一个组合环境。每个场景连续执行 8 状态；39 规则形成 312 格/端，303 必评、9 不适用。两端桥接只解码并调用同一个生产组件，公开/隐藏桥接字节相同，不按场景 key 重建组件。

两组首采：Android 271P/0F/32U，iOS 265P/6F/32U。六个 F 是同一个视觉原因在不同状态出现，不是六个 bug：SwiftUI 原生禁用按钮在显式配色之上继续淡化整个 label。两组独立使用保留 label 的 ButtonStyle，保留 `.disabled` 与业务语义；Android 源码均未修改。隐藏初始参考的深色按钮实际 `#FF223229`，独立预期 `#FF344A3C`；两份最终原图均符合预期。[原图和源码](GALLERY.md)。

修复者各有 20 分钟、两次诊断请求，不延长。D1 因共同调用方传错 `--previous` 包类型而拒绝，双端均未启动 SDK；D2 只改正包路径，默认规划器两组都选择全 8 状态，未取得定向缩减收益。截止时间自动封存源码；各自再做新的全量公开 Final，源/自验一起关闭后才运行隐藏。两名独立匿名评估者和第三名共因匹配者封存后才揭盲。[屏障链](gates/reveal.json)固定全部前置证明。

## 为什么仍没有质量和成本优势

这次自然初版只有一个视觉缺陷，旧版原子像素断言也能检测，新增动作/责任保护没有遇到能区分结果的产品错误。新增保护在中性负例证明了阻断能力，不能把中性拒绝数算成盲测多发现的产品 bug。

新版每次 iOS 原生采集都创建并退役自有设备；基线在共同安全层持有的单一实验设备上复用。D2/Final 的 XCTest 本体耗时相近，但新版设备冷启动每次约 23 秒，基线约 0.3 秒。生命周期更明确，端到端更快没有成立。磁盘峰值改善与默认回收一致，但只是一次配置路径的采样值，不能把全部差异单独归因某个子功能。

两组 D2 都保守全量复验；没有源码变化时，协议仍要求新的全量 Final，造成重复运行。Swift 改动也使全 PR source fingerprint 失效，Android 同样复验。后续通用改进应先验证有界设备池安全复用、按端/责任建立失效依赖，以及采用已满足“当前源码＋全量＋完整收尾”条件的原包完成最终门控；这些尚未实现或获得本轮成绩，不能回头改协议把 D2 算作 Final。

121.87 分钟是两组共同的独立完整验收端点，包含隐藏屏障、原始初版隐藏参考、双评及共因匹配，不意味着单独跑一个 PR 也会相同。共同评估适配器发生过原版本路由不匹配、历史包不完整导入等错误；全部记录后，在完整原冻结工具中离线重放解决，没有再采集或改产品。不能将这部分成本或修复记作新版收益。

## CI 为什么连续失败

1. [42633193301](https://github.com/KamisamaJin/native-ui-agent/actions/runs/42633193301)：新增 `action_guard` 无条件导入破坏旧入口通过 importlib 单文件加载的兼容性。合并运行测试时的 `sys.path` 污染掩盖了问题。修复为仅在新 guard 协议加载依赖，增加独立 `python -I` 回归，守卫判据未放宽。
2. [42636803387](https://github.com/KamisamaJin/native-ui-agent/actions/runs/42636803387)：v9 历史重放读取更新后的活 `THIRD_PARTY_NOTICES.md`，和当年封存 SHA 不同。现在只从受控历史目录解析**摘要完全相同**的旧字节，错误摘要、路径越界与错误基线仍拒绝；前置检查 276 个历史别名后继续完整评分。

修复提交 `130eb88` 的[完整远端 CI 已通过](https://github.com/KamisamaJin/native-ui-agent/actions/runs/42733246315)。原失败日志、原清单、评分与历史源码不重写。最终业务发布另外加入全部屏障/证据核验和 18 个原冻结运行时重放；CI 不会启动模拟器。最终发布绿灯以 GitHub 对应提交为准，旧提交绿灯不替代新检查。
