# 暂不执行的原生接入要求

以下是同一通用探针的原生补证需求，不是业务盲测。没有合适 SDK、项目桥接或明确授权的目标时记 U，不能从命令替身、合成 AX、源码或已有截图推出成功。

## N01：借用设备的原状保护

只接收调用方明确指定的隔离测试设备句柄；记录设备身份、启动状态及本轮实际使用的 App/测试进程。对原本已启动的借用设备，正常、异常、SIGINT、SIGTERM 结束后不得关机、删除设备或重置用户数据。共享设备运行中的其他 App/进程和内容不得成为按名清理的对象。不得使用 `shutdown all`、`erase all`、按名称删除或创建全局设备。

验收需要真实设备前后状态及命令日志，不接受仅有“borrowed”布尔值。若测试者不能安全检查既有共享内容，则只测隔离目标并明确限制，不能宣称保护了所有设备。

## N02：本轮改变的设备与运行时资源

若调用方另行允许使用一个既有、初始关闭的专用测试设备，本轮启动后须按明确租约策略恢复初始状态；原本已启动的设备不能被同一清理策略关闭。验证正常退出及异常/取消后恢复。崩溃后由明确的 reconcile 操作处理本轮遗留租约；有活体其他使用者或身份不确定时拒绝破坏性恢复并保留未回收状态。

不允许为了本探针新建或删除全局设备。没有安全的现成设备和授权时，该行保留 U。确切恢复策略必须在运行前写入接口/输入，不能看结果后选择“保持启动”或“关机”任一有利判据。

## N03：真实派发与因果前置条件

使用无业务含义的计数器控件：可用按钮、禁用按钮、可由调用方替换的计数值。实际生产薄桥接调用此探针组件；SDK 采集真实点击、即时帧、回调和同进程输入更新。分别验证成功派发、禁用阻塞、目标缺失、原生多目标歧义、调用方更新未完成及动作异常。

成功派发应使指定依赖满足；未实际派发的动作即使画面恰好已是目标状态，也不能建立该因果状态、零回调行为或下一依赖动作通过。独立观察当前标签的真实事实仍可保留。每种平台只声称实际演示的派发路线；Android semantic OnClick 不计为 OS 物理点击，iOS AX 边界不计为物理命中区。

## N04：宿主/组件/系统责任及原生来源

同一小组件由宿主放在有明确背景的区域，系统提供独立可识别的系统 UI。封存三层责任后，分别在合法协议输入中检查当前 frame、层级、像素与动作事实的声明边界，不主动制造产品缺陷。宿主绘制的 canvas 或系统变化不能自动计成组件缺陷；原生属性只在实际可读取的 API 范围内评分。缺少 computed font/padding 等能力须 U。

任何原生样本都记录实际测试发现/执行数量、真实环境、原始图片、源码、输入、进程及事件绑定。测试数为零、环境不符、旧图片、无 native 方法证明不能接受。协议色板和合成节点用例仅测证据校验，不用于替代本行。

## N05：原生中断和残留证据

在实际 SDK 运行期间取消或仅杀死本轮管理者，确认本轮拥有的 xcodebuild/Gradle/测试子进程或专用宿主生命周期按租约回收；其他会话、借用设备、已有编译缓存、生产源文件和原始证据得到保护。重启后的 reconcile 不得基于旧 PID 结束身份不同的实际进程。

异常不能产生交付 `accepted`，即使目录中已有部分有效图片。允许保留能明确绑定的局部事实，但原始异常、未完成动作、未覆盖状态和清理失败须在结果与账本中可见。每个变体有独立的新鲜输出，不以正常结束代替异常测试。
