The independent typed plans were derived from brief/BRIEF.md, API.md, reference.svg, cases.json and the fixed native mappings before source implementation. They preserve every public state and the original action route/index. The public fixture/action files remain untouched. Enriched actions only add post-action observation targets; no activation or sweep is added.

Each platform has a full requirement × selected state matrix. Collapsed breakdown absence stays a typed requirement. Intermediate target coverage cannot establish absence without completed bounded content coverage; those cells must remain unassessed when the observer cannot prove them. Disabled action callbacks require real successful dispatch; blocked disabled actions remain unassessed, while current enablement remains a distinct fact.

The chosen post-action targets omit stable title/caption/section-title and breakdown labels to stay within the native tool's maximum32 selector set. Those facts remain in the plan denominator and can be observed in same-state frames; missing observations are not dropped. The two fixed sweeps per case provide full-content checkpoints only at their prescribed states. Full-content visual passes at target-only states are withheld by the checker; visible failures can still be recorded from local evidence.

Android's exported text-layout values may establish concrete font/color/overflow fields only where the adapter supplies them. SwiftUI native AX does not expose exact font, padding or radius. Those style and physical-hit aspects remain manual/unknown rather than inferred numerically from source. iOS semantic AX bounds do not establish physical touch regions. The public reference fixes tokens and hierarchy rather than incidental y coordinates or cross-renderer pixel identity.

No generic capability probe or product rendering is run in this initial phase because the root experiment explicitly requires D0 source and these original plans to seal first. Actual runtime evidence is delegated to the root's later observation phase, with the resulting limitations retained in the review.
