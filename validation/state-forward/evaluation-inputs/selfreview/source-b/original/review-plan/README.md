# Original independent prefeedback plans

The expected state script reads only the public BRIEF/API/cases and native mapping.
Each platform plan retains every relevant state/copy/control/action aspect, including
checks unlikely to have target-only viewport coverage. Only the fixed two full
sweeps in each case are used. Original stimulus routes/state IDs are unchanged;
post-action observation of charge is requested after job/mode changes.

Run `agent-output/review_native.py` with --plan, --observation, --platform and
--output. It calls this workspace's assigned `skill/scripts/native_checks.py`.
It semantically decodes only the public callback envelope JSON string before
comparison, because the API's dictionary key order is not a behavior requirement.
Raw observations remain intact. Dispatch success/method, enabled uniqueness,
callback intervals and same native instance/input/process gates are unchanged.
Its report preserves original input hashes and all raw/decoded callback receipts.
Running the assigned checker directly without decoding would compare encoded
JSON strings to public expected dictionary values, a transport mismatch.

Full-content style claims at target-only checkpoints remain unassessed when not
covered. Disabled observer-blocked activations remain unassessed as handler
behavior even when their disabled native state and empty interval are observed.
Compose stateDescription is not exported by the assigned Android observer; its
native-expanded assertion is preserved as an unsupported property, not guessed.
iOS font tokens, padding/radius and physical hit regions are not exported by AX;
AX width/height measurements and visual intent are separate checks. Exact SwiftUI
style checks remain unassessed unless actual independent pixel measurements exist.
The wrapper decodes data transport only and supplies no missing measurements.
