# State evidence v5: methods before the next business design

This iteration addresses generic multi-target post-action evidence and explicit
state-by-aspect planning. The v4 publication, native captures, expectations,
scores and failures remain unchanged. A frozen v4 Skill is the comparison arm.
Historical publication aliases are reconstructed from their original byte copies
for checks that originally asserted the live Skill/README/workflow were v4.

## Engineering before design

- Keep the exact successful-dispatch callback gate. An observation set never
  extends the immediate action callback interval or activates a target twice.
- Observe a declared set of exact native targets after actions or caller updates;
  reuse already valid state frames and scroll only for remaining targets. Bound
  search, explicit missing/ambiguous targets and input/event drift remain visible.
- Union evidence only within the same input, native process and event revision.
  This is target coverage, not full-content coverage. Conflicting values remain U.
- Compile selected states and requirement aspects into a complete atomic plan.
  Every selected state must have an expected value or explicit not-applicable
  reason for each selected aspect; do not silently omit later related states.
- Produce exact machine findings by state from real checks; keep manual findings
  separate. A shared-cause repair does not retroactively establish detection.
- Validate with neutral, independently chosen components before freezing v5.
  No business expected values, implementation sources or images will be supplied
  to that independent capability validator.

No generic SwiftUI font/padding inspector, arbitrary legacy-page locator or OS
Android touch capability is implied. Unsupported style aspects remain in the U
denominator. No threshold will be fitted to the next business result.

## Fresh blind comparison

After generic validation and tool freeze, an independent context fixes a new
business design, public API/reference and full acceptance before either builder.
Exclude prior attachment/upload/transfer/appointment/returns/watering domains.
Use pinned Reply and AlertToast production modules with equal dependencies.
Both arms use the same default model settings and a Skill; compare frozen v4
against frozen v5, not against a new no-Skill arm.

Keep four initial cases and two held-out cases, 320/390-wide by 600-high hosts,
at most two models, eight non-sweep actions and two full-content checkpoints per
case. The independent design chooses business-specific combinations and content.
State targets and typed check plans are builder-owned outputs derived only from
public requirements; the independent acceptance denominator is fixed separately.

Each builder has at most 25 minutes implementation, 12 minutes read-only review,
one 15-minute repair; early completion is allowed. Seal both D0 sources before
feedback, each review before repair, and both FINAL sources before holdout native
inputs. Report actual continuous implementation-to-own-final-corpus wall time,
phase sums, barriers, all native commands and experiment-only scoring costs.

Use both-source common-observer D0/FINAL scoring, followed by original self-review
matching and same-source v4/v5 D0 pairs. Seal both anonymous outputs in each batch
before delivering the next batch; reveal assignment only after all seals.
Preserve all gains, losses and assessed disagreements; no selective best image.
Shared filesystem and recognizable output formats limit procedural blindness;
there is no human gold standard or causal quality claim from one task per arm.

## Denominators and attribution

Report callback/transition behavior only after established requested stimulus.
Keep current native state facts separate: observing a disabled control's label
does not prove an unavailable activation handler or a successful zero callback.
Input-member checks and source/API declarations do not inflate runtime coverage.
The independent evaluator must freeze this classification before seeing sources.

Retain all required P/F/U cells, uncertain and unmapped claims, holdouts, raw
failures and fixed-row F-to-P/F/U repairs. Zero natural defect denominators are
N/A. Classical FP/(FP+TN) needs a complete negative universe; otherwise use the
explicitly conditional false-discovery share. Distinguish manual-only detection
from combined machine-and-manual detection, with original native checks sealed.

Record numerical geometry uncertainty with platform units and original facts.
The next independent grader chooses generic precision rules before reading
candidate results; prior frozen numerical failures are never rescored.
Common host/evaluator/publication repairs are separate from v5 observer benefits.
