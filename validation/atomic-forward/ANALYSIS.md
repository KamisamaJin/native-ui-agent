# Why the previous release did not establish a quality advantage

The original v7 publication remains unchanged in
[its report](../multitask-forward/RESULTS.md) and
[grader disagreements](../multitask-forward/GRADER-DISAGREEMENTS.md).
Its numerical metrology and independent source-backed design contracts did not
close the full chain from a visual observation to a supported product alarm.

1. **Generated numerical expectations did not bind free-form visual findings.**
   Original visual descriptions could still contain different expected values or
   units. Exact-descriptor rejection then understated some semantically plausible
   discoveries. That is a transport/compliance defect, not automatic evidence of
   a false product alarm. The v8 catalog generates identity, expectation, unit,
   operator and provenance; reviewers supply actual observations only.
2. **A combined visual verdict hid which proposition had evidence.** A broad
   statement about color, canvas, structure and wrapping could not identify the
   measured layer or isolate the unsupported aspect. The new policy fixes separate
   atomic propositions and component/host/system responsibility before code.
   Approved flat-color regions are measured from original PNGs and native boxes;
   qualitative wrapping and overlap still require actual visual inspection.
3. **The evaluator itself could dominate the result.** The previous Compose
   direction spelling mismatch gated Android acceptance to unknown. Provider
   Float32-to-integer-screen conversion and inconsistent visual/ownership labels
   further limited interpretation. The shared evaluator now checks the actual
   native wire format, keeps numerical facts authoritative, and retains independent
   qualitative or cause disagreements as unknown. These are shared repairs, not
   exclusive treatment gains.
4. **AX does not expose arbitrary computed SwiftUI styles.** Better naming or a
   stricter prompt cannot produce missing runtime font, padding or physical hit
   facts. Selected unsupported cells stay unknown. Rendered-region color does not
   establish a generic computed-style API or whole-canvas correctness.

The tested response is executable validation rather than a promise that an agent
will read images more carefully. It is frozen before independent new designs,
validated against neutral native acquisitions and negative controls, and compared
with exact v7 on three new task pairs. Both arms already have independent contracts
and native metrology. See [engineering](ENGINEERING.md),
[prospective policy](PREREGISTRATION.md) and [metric definitions](METRIC-POLICY.md).

Binding does not make a mistaken visual observation true. Two model contexts can
also agree incorrectly, and a design owner can approve a poor specification.
Hashes preserve an approval chain; they do not establish independent authorship or
design correctness. The experiment therefore retains original claims, uncertainty,
independent cause memberships, all failures, and actual end-to-end costs. It does
not retrofit expectations or enlarge the scored ledger around a newly noticed bug.
