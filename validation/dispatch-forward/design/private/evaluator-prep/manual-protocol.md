# Frozen independent evaluation protocol

This protocol and its executable matcher precede all candidate source and evidence.
The sealed design and expected values never change. A representation adapter adds
common helper field names and maps only ios.xcui.tap → xcui_tap,
android.compose.OnClick → compose_onclick, caller.replaceModel →
caller_fixture_update. It preserves every original expected JSON value and hash.

## Phase and anonymity barrier

Read only the anonymous D0 common-tool source/evidence batch first. Grade both D0
capsules, seal those reports, then receive and grade FINAL common-tool batches.
FINAL includes all six cases; D0 includes only the four initial cases. Seal both
FINAL reports before receiving the builders' self-reviews. Match self-review
claims to existing frozen finding keys without changing outcomes. Seal matching
before observing paired/counterfactual corpora. Do not infer assignment from source
style, implementation history, execution cost, corpus shape, or an anonymous name.
Do not open an unreceived later phase or unrelated result directory.

A supplied observation may be missing, incomplete, blocked, or invalid. Keep every
required row in the phase plan; unavailable evidence yields U. Grade-row omission,
duplicate keys, substituted expectations, unplanned rows, or cross-phase evidence
are malformed evaluations and are hard errors. No passing aggregate is claimed
while U remains. Keep six denominators: runtime business, runtime visual, runtime
integration, runtime capability, input-member integration, and source API.

## Native dispatch and immutable checkpoint rules

Import the frozen shared contract.py and its same callback_verdict implementation;
do not copy or replace them. All callback P/F must equal the common verdict after
successful requested dispatch, exact native route, same process/instance, caller
input provenance, unique enabled native control, and an exactly bound original
callback interval. Callback intervals remain those of the activation or explicit
caller replacement, never a later scroll sweep. Event arrays are compared exactly,
including order and payload tokens.

The evaluator additionally requires the actual raw dispatch selector to equal the
requested local selector. Mapping pointers may identify only the native step's
selector/target/query or dispatch selector/target/query field. Mapping is a locator,
never independent dispatch proof. An unavailable, refused, absent, ambiguous,
disabled, wrong-method, wrong-selector, stale-input, failed, or unrecorded action
leaves callback behavior U even when the expected array is empty. An empty interval
does not prove handler execution.

All post-stimulus business P/F requires this same successful requested dispatch
binding. The same precondition is applied to post-stimulus visual/integration and
capability rows because the design declares it. Literal receipt facts, model input
facts, source declarations, and observed disabled appearance cannot override a
failed stimulus gate. Observed initial disabled state can be graded independently.

The checkpoint mapping identifies raw native state_id, input_index, original
trigger_action_index, and state_action_index/after_action. The latter two must agree
if both are present. State frame bindings must equal the original stimulus's
binding_after, including event revision. A later sweep may add images only within
that immutable binding. State/input indices are mappings, not expected business
values. The exact captured native fixture file hash must match raw input_sha256.
Each mapped model object must equal the sealed model exactly.

## Exact native matchers

Resolve exact public identifiers with the common native resolver. Never search
approximately by title, tap a guessed coordinate, use a source literal as native
text, or replace a native control with a wrapper activation. Text uses the unique,
visible native label, or native text only if label is absent; compare the complete
string exactly, without normalization, fuzzy matching, or substring acceptance.
Selected state needs an explicit native Boolean trait; absence is U, not false.
Checked state needs the native Boolean toggle value; enabled state requires a
unique native control. A missing target proves absence only after complete native
coverage of that checkpoint. Conflicting values within one immutable epoch yield U.

Bounds use native iOS frames in points or explicitly reported Android dp bounds.
Raw pixel/AX dimensions are not physical hit regions. Expected equals compares
exactly unless the sealed expected object specifies tolerance. A nonnull minimum
is inclusive. Null placeholder comparison members in a sealed range object impose
no comparison. No amount is recalculated in the grader: expected numeric strings
and callback tokens come only from the sealed plan.

Full-content coverage is recomputed from native content/viewport or scroll-offset
intervals, top/bottom reachability and stable binding. A producer's complete flag
alone is insufficient. Adjacent extending intervals require at least 24 logical
units of overlap; one frame that covers the entire component is sufficient.
Missing coverage is U, not an implementation failure. An observed local visual
counterexample can establish a local F without establishing a global layout P.

No planned native-bound rule is silently replaced by visual judgment. For example,
a global descendant-overflow native-bounds claim remains U if complete native
rendered descendant extents are not reported. The visual no-clipping criterion is
judged separately. Runtime typography, internal padding/spacing, native text scaling,
and physical hit regions require original native runtime inspection facts with the
same target, field, platform and binding plus a named native probe. Source code,
AX/semantic outer bounds, a single successful coordinate tap, screenshots, and
Compose semantic OnClick cannot substitute. Unsupported facts remain U in the
capability denominator.

## Manual visual protocol (fixed before images)

Use only original hash-bound state PNGs. Do not resize, recolor, sharpen, crop-save
as evidence, or substitute the reference SVG. Review may zoom the original display
but all measurement coordinates refer to original native pixels. The SVG is design
intent, not a native pixel golden. Cite the exact snapshot indices, PNG paths and
hashes, annotated target rectangle in original pixels, and a concrete witness.
Record U when the criterion cannot be resolved.

For all visual assertions, first establish the named local target from native
identifier bounds or its visible text/control and enclosing card. The witness must
identify which corresponding region is being measured. A full-content P requires
the complete overlapping native interval union. A local F must name the observed
counterexample and explain why it is not a viewport crop or scroll artifact.

- Section order: compare visible sections in the full sweep to the frozen ordered
  list, skipping only the conditionally absent sections. P needs the whole card.
- No truncation: compare every supplied and fixed string with the visible glyphs
  throughout the sweep. P requires all strings and no ellipsis/clipping/horizontal
  content loss. F names the specific string, image and location. Missing offscreen
  text with incomplete coverage is U.
- Direction: in the frozen RTL/LTR host, inspect leading/trailing text alignment,
  choice indicator placement and summary arrangement, while preserving vertical
  order. State the witnessed leading edge/control arrangement.
- Fill and foreground color: annotate three independent patches inside the target.
  Fill/container patches are at least 3×3 native pixels, away from border/text/
  shadows. Foreground and border patches may be 1×1 native pixels and must be in
  opaque interior strokes. Avoid antialias edges and selection/focus overlays.
  The program reads original PNGs and takes per-channel median for each patch.
  All three patches within the frozen per-channel tolerance establish P; all three
  outside establish F; mixed results yield U. Fully opaque palette evidence needs
  opaque raw pixels. A reviewer cannot override this computed result.
- Border width: annotate endpoints spanning an actual straight perpendicular
  border cross-section, and explain chosen inner/outer edges. Use at least two
  separated straight edges when visible. Measure original pixel distance divided
  by native screenshot scale; never estimate from a source declaration.
- Corner radius: annotate the corner's tangent intersection/center and the matching
  horizontal or vertical radius segment. Use at least two unobscured corners when
  visible, and explain tangent selection. Measure native pixel segment length
  divided by recorded native scale. If rounded edges cannot be located reliably,
  choose U. Never fit the SVG to the screenshot as a golden.
- Geometry units: the native scale must agree with original PNG width divided by
  raw viewport width in points/dp. Missing native logical viewport scale yields U.
  Exact internal padding, physical hit regions and native typography stay in their
  separate native capability rows; manual pixels cannot grade them.

The visual decision file is a complete or partial list of decisions. Omitted
visual rows become U automatically. Do not claim exact font size/weight from glyph
appearance. Measured geometry and color outcomes are checked by evaluator.py;
qualitative review remains explicit reviewer judgment with evidence.

## Source/API and input provenance

Input-member rows compare each exact immutable captured fixture member to the
sealed member and remain input-member integration facts. They cannot prove that a
production handler executed, a view used the member, or any visual requirement.

Source/API P/F is a separate read-only source review, never a runtime result.
Review the actual anonymous production entry point, public definitions, required
constructor members, callback alternatives and field types, deployment compatibility,
modifier flow and thin bridge. Inspect the complete relevant implementation for
forbidden bridge behavior; a coincidental literal is insufficient. Give exact
hash-bound source file and line-range citations with verbatim quotes. Negative
claims such as “no calculation in bridge” need the complete bridge range. Compatibility
claims need deployment settings plus all potentially later API uses in the new
library files. A declaration is insufficient for honoring the Android Modifier:
trace its flow into the production root. Each decision preserves the exact frozen
expected-value hash. When the relevant source is absent or unclear, use U.

The evaluator validates citation hashes and line text; semantic source assessment
remains a named reviewer judgment. It never imports or executes candidate source,
nor uses those judgments to override native behavior/style/capability grades.

## Report and archival validation

Emit every phase key exactly once, P/F/U, its unchanged expected hash, compact raw
evidence references, actual native value or measured fact, reason, denominator and
the shared stimulus-gate verdict. Recompute the common precondition in archival
validation; reject callback P/F that differs from callback_verdict and reject any
post-stimulus runtime P/F without requested native dispatch binding. Recheck
native-control/text/bounds and capability grades against original native fields.
Retain observation attempts, failed captures and unsupported requirements in U.
Aggregate P/F/U per denominator and platform; never merge input/source receipts
into business coverage or remove capability U to improve a percentage.
