# Accepted native component design cohort, revision 2

This cohort retains T1 byte-identically and independently replaces T2/T3 after a preimplementation breadth review. The original `design/` cohort remains unchanged. At selection time there were zero production candidates, zero candidate SDK commands and no rendered candidate feedback. No outcome-based selection or deliberate defect was used.

| Task | Concrete composition | State/workflow |
|---|---|---|
| T1 ExpeditionPackPanel | Two equipment cards, weather option, disclosure, weight/readiness summary | Select equipment, resolve weight/shelter constraints, confirm and caller reset |
| T2 BroadcastCueMixerPanel | Live/Preview segments, three channel ledger rows with minus/level/plus/mute controls, load/headroom monitor and conditional overload banner | Edit one stored channel level, switch mode without losing levels, mute while preserving level, apply all channel states and replace session |
| T3 CollectionConditionReviewPanel | Three-row object queue, focused object inspector, vertical condition choices, conditional care-category section, aggregate review/follow-up summary | Classify and justify a record, navigate to another record while preserving decisions, respect read-only records, validate required completeness, submit all decisions and replace review |

The shared oracle consumes arbitrary approved targets and independent action indices. It has no assumption of two equal-width choices or a common control arrangement. Generic oracle/tool-pin files retain their original bytes so copied T1's original seal remains valid after relocation. `T1-REUSE-BASIS.json` verifies every copied task byte and explains the reuse basis. Original T1 control results remain untouched; the new relocation check is recorded separately.

Each task fixes 22 rules × 6 selected states × 3 cases × 2 platforms =792 denominator cells. P1 is normal/light at offered width390. P2 is narrow/dark at320 with xxxLarge/1.6 text. H1 changes ordinary input/seed combinations under public rules. Each case includes original full-content loaded and replaced sweeps, real taps and same-mounted-component caller replacement. T1/T2 use five non-sweep actions; T3 uses six. Disabled stimuli explicitly allow blocked observation and retain U for callback behavior without successful dispatch.

Builders receive only their own public task directory and cannot read public/compiled or private data. They must compile fresh plans themselves using approved typed locks/digests and frozen tools. Common observation/grading uses the sealed compiled case roots: fixtures.json, actions.ios.json, actions.android.json, plus ios/android plan/action files.

SDK-free grader entry points are `T1/private/grader.py:grade`, `T2/private/grader.py:grade`, `T3/private/grader.py:grade`. All wrappers resolve the accepted root oracle_common.py. T1 retains its18 original controls; each new task adds22 structurally generic controls including actual native geometry and derived-summary corruption. No control mutates production code. New actual CLI seal/compile commands and their equality to approved plans are preserved per task. iOS computed styles remain U; visual decisions require original state PNGs/hashes. Input/API integrity remains separate; paired acceptance comparison includes native classes only.

COHORT-SEAL commits to the unchanged accepted T1 seal, new T2/T3 seals and all shared code/metadata. Do not edit any sealed expectation, input, API, reference, precision, acceptance table, grader or control after implementation begins.
