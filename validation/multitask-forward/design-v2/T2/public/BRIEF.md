## Composition and business workflow

This is a three-channel mixing desk, not a product-choice card. Render a Live/Preview segmented control, followed by a channel ledger in caller order. Each channel row has name, caption, a minus button, numerical level, plus button and Mute/Muted button. Minus/plus change level by exactly one within 0...maxLevel. Locked channels disable all three row controls. Muting retains the stored level. Mode changes retain every level and mute flag. Seeds clamp levels to 0...maxLevel and preserve caller mute/lock flags. Live load sums the level of every unmuted channel; audible count counts unmuted channels with level>0. Headroom is maxLiveUnits minus load and may be negative. The grouped monitor shows `N audible • LOAD / MAX units`, `Headroom: N unit[s]` (singular only when N=1), and Live mode/Preview mode. When load exceeds maxLiveUnits, show a separate warning `Over live limit by N unit[s]`; otherwise that warning node is absent. Apply mix requires at least one audible channel and either preview mode or a load within the live limit. Preview permits applying an overloaded mix but never hides the live-limit warning. Confirmation sends every current channel and mode without resetting local values. Replacement request.id restores every channel level/mute flag and mode from the new caller seed. No nested disclosure is used.

All supplied long note paragraphs appear in order below the primary action under Operator notes. Assign the heading identifier `mixer.notes`. Title and context use caller values. Primary label is `Apply mix`. Native controls expose exact unique identities from bindings.json, real disabled state and selected semantics for selected modes, muted controls, active queue rows and classification/reason choices. Native selected trait: SwiftUI accessibility selected trait; Compose selectable semantics. Keep dedicated text nodes for title, current level/summary, focused title and inspection note where present. Do not nest a native OnClick inside another OnClick control.
