# v7 engineering and experiment boundaries

The baseline is the exact v6.1 release at249aae5c. Both arms already have the
independent design contract, expectation-source verification, state coverage,
dynamic native targeting and PNG deduplication. This trial compares the additional
v7 measurement changes; it does not compare all prior infrastructure with an
unassisted implementation.

Previous equal product scores did not establish a quality benefit. There were no
independently confirmed natural defects in that trial's chosen denominator. Three
strict Android size failures came from Float endpoint conversion/subtraction, and
three previously assessed pair cells became U when near-boundary readings disagreed
across frames. Neither is three independent business bugs. Forty-eight iOS computed
style unknowns and two unexecuted disabled-callback observations were real limits.
The old scheduling breach is preserved in its original publication.

The v7 implementation retains native Compose integer pixel extents, Float position
promoted to Double before further arithmetic, and native density. Rational
operations use those recorded samples. Direct CGRect widths/heights avoid a second
endpoint subtraction on iOS. Exact provider/sample/selector/frame provenance is
retained. No global epsilon, acceptance snapping or silently wider tolerance was
added. Missing legacy packets use the explicitly labelled original calculation;
malformed new packets remain unknown. This removes one source of false failures
and mixed-frame unknowns, without declaring upstream AX values mathematically exact.

Neutral checks expose that limit: iOS can itself return51.999999999999986 or a
transient scrolling extent. Those strict failures remain recorded. They are not
silently converted into passes or automatically classified as production defects.
SwiftUI computed typography/colors and unsupported layout allocation remain U.
The successful callback-dispatch prerequisite is AST-identical to the baseline.

All tool changes were tested on neutral native hosts, independently forward-tested,
then frozen before new business tasks were written. Controls that intentionally
alter synthetic observations are metrology/evaluator controls only. No production
candidate was seeded with a bug. The initially independent three-task proposal was
rejected before any implementation because its interaction structures were too
similar. Its complete seal remains available. A second independent sealed cohort
contains selection/eligibility, a multichannel mixer, and a persistent review queue.

Whole-cohort launch tickets check exact membership, dependency hashes and actual
source/inputs before SDK launch. This closes the previous accidental early launch;
it is a procedural barrier, not a security sandbox against a malicious agent.
The real early-launch rejection, all original sources/plans/reviews, failed native
attempts and original grades remain published. Assignment stays hidden from the
independent evaluator until all three tasks finish all four grading stages.

Actual v6 and v7 native sessions on identical D0 source/input are reported separately
from development quality. V7 pair scores reuse the sealed common D0 native-base
bytes, never a better regrade. A second, preregistered offline comparison runs both
frozen checkers on identical v7 observation bytes to isolate arithmetic from
scrolling/timing. No visual review, API check or input check counts as a collector
coverage gain.

Shared scheduling was registered before original review/repair or common grading:
public D0 audits can overlap model phases in separate workspaces, with two globally
locked native-acquisition slots. This scheduling is shared experiment infrastructure,
not a v7 speed gain. Primary latency includes all actual barriers and resource waits;
audit acquisitions, model review, grading and the full experiment wall are separate.
The fixed22-family ledger does not cover every sentence of each design brief.
Unasserted scope and supported-observation coverage must not be called full spec
coverage. Independent AI review is not a human-labelled gold standard.
