# What this experiment can establish

These are three prospective component-development task pairs in pinned public
Reply and AlertToast checkouts. Original upstream production files are retained;
new standalone production components are exercised by independent thin hosts.
They have approved public APIs and explicit accessibility/semantics identifiers.
This does not establish fuzzy targeting accuracy on arbitrary uninstrumented legacy
screens, navigation/integration quality of a complete app, or backend integration.

iOS acquisitions execute actual XCTest on the recorded Apple Simulator runtime.
Android acquisitions use the Paparazzi/Compose JVM test host and its recorded native
semantics/rendering environment, not an Android emulator or physical device.
Simulator/layoutlib results do not establish all real-device behavior. CI replays
published evidence and integrity/accounting controls; it does not repeat the SDK
acquisitions on the Linux runner.

The fixed22-family ledger is a selected denominator, not every requirement in the
brief. Independent graders explicitly list unasserted scope. Public AX does not
provide generic computed SwiftUI fonts/colors; those numeric cells stay U even if
source literals or screenshots look plausible. A visual composition contradiction
can coexist with an unknown computed-color assertion. Semantic/AX rectangles are
not all underlying layout allocation, literal padding constraints or OS hit regions.
Android's integer `SemanticsNode.size` is a native layout extent; it does not by
itself certify the painted axis-aligned extent after graphics transforms, ancestor
clipping or glyph rendering. This cohort does not establish those cases. Exact
arithmetic on recorded samples is not a general renderer-accuracy guarantee.

Common D0/FINAL acceptance sees anonymous sources and the same frozen collector.
All three tasks seal before the next grading stage is delivered. Original review
matching occurs only after both quality stages seal; trace formats there can suggest
the original tool version. Source-arm assignment is formally withheld until all
pair grades seal, but this is procedural minimum-context isolation on a shared
filesystem, not a secure sandbox or an assurance that versions cannot be guessed.
All grading is independent AI review, not a human-labelled gold standard.

Strict original-claim accounting requires case/platform/state/requirement, original
expected/unit and original evidence. Broad or unmapped observations remain explicit
uncertainty; lack of exact descriptor credit is not proof that an agent never noticed
the issue in prose. Successful manual observations are retained outside a failure-claim
denominator. Exact restatements of typed failures cannot earn extra manual discovery
credit. Shared accounting guards do not change frozen tools or acceptance truth.

Product defects are classified separately from strict numerical failures,
observation limitations and design-resolution problems. Repeated states and two
platform manifestations are not independent bugs. Per-task/component clusters and
their recurring failure classes must both be described; three pairs are too few for
a general causal quality or speed claim. A zero natural-defect denominator is N/A.

Primary latency runs from actual implementation start to the unit's own FINAL raw
corpus seal. Complete public-cohort closure additionally includes every final typed
check. Both include earlier experimental barriers; global barriers are not ordinary
single-component production latency. Model wall includes compiler waits. Native
command sums overlap across platforms/slots. Public audits can overlap model phases
under two shared native locks. Report all observed work, queues and full experiment
wall separately; do not attribute shared scheduling or old cache infrastructure to
v7. Token and monetary usage were not exposed and are unavailable.
